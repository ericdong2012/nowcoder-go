## 使用建议

1. **先自己写再看答案**：文件先看题目部分，手写后再对照思路和代码。
2. **每题跑自测**：`python 文件名` 全绿才算过；改代码观察哪个断言挂——这就是最小回归测试的习惯。
3. **重点题型复写**：二分边界（65/66/67）、BFS/DFS（51/52/41）、背包 DP（85/89）、单调栈（72/73）
   每类隔几天盲写一遍。
4. 目标（路线 9.2）：热题 100 完成 60 题 + 会讲思路 30 题；现场手撕优先练：23、35、53、59、68、93。
